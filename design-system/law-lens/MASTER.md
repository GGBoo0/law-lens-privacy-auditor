# 법령렌즈 화면 기준

기준일: 2026-09-12. 사용자 요청에 따라 [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/main/README.ko.md)의 실제 스킬과 검색 데이터를 참고했습니다.

## 선택한 방향

`legal compliance review workspace` 검색의 Accessible & Ethical 스타일과
`document analysis tool workspace` 검색의 Minimalism & Swiss Style을 적용합니다.
검색 결과의 영업·가격·고객 사례 중심 랜딩 구조는 이 앱의 작업 흐름에 맞지 않아
사용하지 않습니다. 기존 입력 → 점검 → 근거 대조 → 검토 기록 흐름을 유지합니다.

## 색상과 서체

- 배경 `#f6f5f1`, 본문·주요 버튼 `#172c48`, 보조 본문 `#5c6877`, 흰색 작업 영역.
- 금색 `#946526`은 제목 강조, 연한 금색 `#f2dfb8`은 작은 강조 배경에만 사용합니다.
- 오류·주의·확인의 의미는 색상뿐 아니라 텍스트로 표시합니다.
- 검색 결과의 영문 서체 대신 기존 자체 호스팅 Pretendard를 유지합니다. 한글 본문과 외부 전송 최소화에 적합합니다.
- 본문 16px, 설명 12–14px, 결과 제목 16px 이상. 모바일 입력은 16px 이상입니다.

## 화면과 조작

- 첫 화면에서 입력 방식·입력란·분석 버튼에 접근할 수 있게 소개를 줄입니다.
- 점수의 비법률적 의미는 점수 바로 옆에 유지합니다. 법령 검토 대기 상태를 숨기지 않습니다.
- 보고서 바로가기는 점검 결과·기재 항목·법령 근거·분석 원문으로 연결합니다.
- 분석 원문으로 이동하면 접힌 원문을 펼칩니다. 근거 버튼은 실제 표시 위치에 초점을 둡니다.
- 긴 URL·결과 제목·상태 문구는 줄바꿈합니다. 필터 모음은 다음 줄로 배치합니다.
- 주요 조작의 높이는 44px 이상, 키보드 초점은 3px 테두리로 표시합니다.
- 버튼은 색상으로 반응하며 주변 배치를 움직이지 않습니다. 모션 감소 설정을 존중합니다.
- 필터로 숨긴 결과와 접힌 상세는 PDF에 모두 포함하고, 검토 메모는 높이 제한 없이 인쇄합니다.

## 확인 범위

375 / 768 / 1024 / 1440px에서 입력·샘플 분석·결과·원문 이동을 확인합니다.
숫자로 법률 정확도를 주장하거나 전문가 검토 완료 상태를 새로 만들지 않습니다.
