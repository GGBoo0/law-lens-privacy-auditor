# 홈과 검토 작업 화면

적용일: 2026-09-12. 사용자의 “설명을 빼고 핵심 기능 위주로” 요청을 우선합니다.
기존 MASTER의 색상·접근성 기준은 유지하고 화면 구성은 다음으로 갱신합니다.

## 화면

- 소개 문구, 진행 단계, 우측 가이드, 검토 범위와 작동 원리 섹션을 제거합니다.
- 첫 화면은 760px 이내의 단일 입력 패널: URL/원문 탭 → 입력 → 추가 설정 → 분석하기 → 샘플로 체험.
- 추가 설정은 접힌 상태로 제공합니다. 긴 보안·평가 설명은 개인정보 처리·평가 방법 페이지에서 확인합니다.
- 결과는 요약 → 점검 항목 → 근거·원문 순서로 둡니다. 평가 축과 감지 맥락은 결과 아래의 접힌 세부정보에 둡니다.
- 발견 문구, 권고 조치, 검토 기록, 원문 왕복과 PDF/JSON 저장을 유지합니다.
- 점수의 의미와 전문가 평가 전 상태는 각각 한 줄로 표시합니다.
- 네이비·흰색·회색과 자체 호스팅 Pretendard, 입력 16px, 주요 조작 44px 이상을 유지합니다.

## 스킬과 검증

설치된 UI UX Pro Max의 기존 Minimalism & Swiss Style 방향과 오류·재배치 지침을 사용합니다.
`progressive disclosure concise content --domain ux` 검색은 제목 줄바꿈·긴 내용 처리 결과만 반환했으므로,
이번 삭제 범위는 사용자의 명시적 요청에 따라 정했습니다.

빈 입력 오류 초점, 실제 샘플 분석, 검토 항목 및 원문 왕복, 좁은 화면의 가로 넘침을 확인합니다.
법령 판정 규칙과 교정 데이터는 변경하지 않습니다.
