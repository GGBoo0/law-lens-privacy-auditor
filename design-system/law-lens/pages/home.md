# 홈과 검토 작업 화면

적용일: 2026-09-12. `MASTER.md`를 유지하고 홈 화면에 다음 세부 기준을 적용합니다.

## 설치된 스킬 사용

로컬 `ui-ux-pro-max/SKILL.md`와 실제 검색 스크립트를 읽고 실행했습니다.

- `document analysis tool workspace --design-system`: Minimalism & Swiss Style의 정렬, 여백, 명확한 정보 위계를 적용했습니다.
- `error summary validation --domain ux`: 입력란 옆 오류 메시지, 오류와 필드 연결, 오류 위치로 초점 이동을 적용했습니다.
- `text reflow spacing --domain ux`: 좁은 화면과 글자 확대 시 내용 재배치를 확인했습니다.
- `document review workspace`의 디렉터리 패턴과 영업용 Hero/Features 구성은 문서 검토 도구에 맞지 않아 사용하지 않았습니다.
- React 반응형 서체 검색은 결과가 없었으므로 관련 권고를 받았다고 주장하지 않습니다.

## 화면 방향

- 배경을 `#f4f5f7`로 조정하고, 흰색 문서 입력 영역과 `#172c48` 검토 가이드를 나란히 배치합니다. 760px 이하에서는 한 열로 정리합니다.
- 소개 문구를 줄이고 입력 탭, 필드, 분석 버튼의 위계를 강화합니다. 실제 입력→결과→검토 기록 상태가 상단 단계에 반영됩니다.
- 자체 호스팅 Pretendard와 기존 남색·금색 계열을 유지합니다. 본문과 입력은 16px 이상, 일반 조작은 14px 이상을 기준으로 합니다.
- 결과 상세는 제목, 발견 문구, 권장 조치, 사람의 검토 기록을 구별합니다. 접힌 항목에도 기록한 검토 상태를 표시합니다.
- URL 입력 앞 고정 접두사를 없애 전체 주소를 붙여 넣기 쉽게 합니다. 선택 설정은 직접 지정한 개수를 보여 줍니다.

## 조작과 접근성

- 빈 URL과 짧은 본문은 해당 필드에 초점을 두고 `aria-invalid` 및 `aria-describedby`로 오류를 연결합니다.
- 통신 오류는 오류 안내에 초점을 두고 이전 결과를 유지합니다. 취소하면 분석 버튼으로 초점이 돌아갑니다.
- 원문에서 점검 항목으로 돌아오는 버튼은 항목을 펼치고 제목에 초점을 둡니다. 현재 필터에 항목이 포함되면 필터를 유지합니다.
- 조작 높이 44px, 뚜렷한 키보드 초점, 모션 감소 설정을 유지합니다. 검토 기록의 인쇄 표현도 유지합니다.

## 실제 확인

- 프로덕션 빌드 성공, 자동 테스트 143개 통과·1개 의도된 제외.
- 375 / 768 / 1024 / 1440px에서 문서와 주요 영역의 가로 넘침 없음.
- 루트 글꼴 200% 및 모션 감소 상태에서 핵심 결과 화면의 가로 넘침 없음.
- URL/본문 빈 입력 오류와 초점, 샘플 분석, 접힌 검토 상태, 원문 강조 및 항목 복귀 확인.
- 느린 응답 취소 후 버튼 초점 복구, 통신 차단 오류 후 안내 초점과 이전 결과 유지 확인.

법령 판정 규칙과 법률 검토 대기 상태는 이번 UI 변경 범위에 포함되지 않습니다.
