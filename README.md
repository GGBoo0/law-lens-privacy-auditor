# 법령렌즈

공개된 회사 웹사이트에서 개인정보처리방침을 찾고, 대한민국 개인정보 보호 법령 기준으로 누락·모호성·위반 소지를 점검하는 웹앱입니다.

## 주요 기능

- 회사 홈페이지 또는 방침 직접 URL에서 개인정보처리방침 탐색·추출
- 수집이 차단된 사이트와 PDF를 위한 원문 붙여넣기 분석
- 개인정보 보호법 제15조·제17조·제22조의2·제23조·제24조·제26조·제28조의8·제29조·제30조·제35조~제37조의2 점검
- 위치정보법, 신용정보법, 전자상거래법, 인공지능기본법 관련 신호의 조건부 점검
- 근거 문구, 적용 조문, 수정 권고와 자동 판정 신뢰도 표시
- 외부 AI API·유료 데이터 API·앱 데이터베이스를 사용하지 않는 요청 단위 분석
- 규칙과 문장 패턴으로 포괄 표현·문단 간 불일치·현장 검증 필요사항 분리

## 비용 원칙

분석 엔진은 외부 AI API를 호출하지 않으므로 분석 1건당 API 비용은 0원입니다. 공개 페이지를 가져와 메모리에서 검사하고 결과를 저장하지 않습니다. 다만 배포 플랫폼의 무료 사용량을 초과하면 호스팅 비용이 발생할 수 있습니다.

법률 리스크의 조기 발견을 위한 자동화 도구이며 변호사의 법률의견을 대체하지 않습니다.

## 로컬 실행

Node.js `>=22.13.0` 환경에서:

```bash
npm install
npm run dev
```

검증:

```bash
npm test
```
